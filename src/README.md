# Cavity QED Simulations

Consolidated quantum optics simulations using QuTiP.

## Structure
- `src/models.py` — core logic
- `scripts/` — analysis scripts
- `data/` — .qu files
- `plots/` — figures

## Usage
```bash
python scripts/coupled_two_excitons.py
python scripts/concurrence_entropy_analysis.py
python scripts/wigner_fock_plots.py
